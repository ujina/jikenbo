# 事件簿（行政書士の案件管理）

行政書士の事件簿（業務帳簿）を、ブラウザだけで管理できる1ファイルのWebアプリです。
インストールやサーバーは不要で、`index.html` を開くだけで使えます。

**試す**：https://ujina.github.io/jikenbo/

## できること

- **事件簿**：受託番号・受託年月日・依頼者の住所氏名・案件の名称・報酬額・職務上請求書№・備考を記入し、一覧・検索・年ごとの絞り込みができます。受託番号は「2026-001」の形で自動で入ります。
- **経過記録**：案件ごとに、日付・区分・内容で進み具合を時系列に記録できます。
- **見積書**：案件から見積書を作り、A4のPDFで保存できます（内税・外税、10%対象と対象外の内訳、見出し行に対応）。
- **フォルダを開く**：案件ごとに Mac のフォルダを登録し、ボタンで Finder を開けます（下記の準備が必要）。
- **書き出し**：一覧をCSVで保存したり、表をコピーして Excel などに貼り付けたりできます。

## 使い方

1. このリポジトリの `index.html` をダウンロードします（緑の「Code」→「Download ZIP」、または上のURLを開いて保存）。
2. ダウンロードした `index.html` を Chrome などのブラウザで開きます。
3. 左の欄から案件を記入して「保存する」を押します。

## データについて

- 記入した内容は、**開いたパソコンのブラウザの中だけ**に保存されます。インターネット上には送られません。
- ブラウザごと・パソコンごとに別々の記録になります。ブラウザの閲覧履歴やサイトのデータを消すと、記録も消えることがあります。
- 一覧の下の **「バックアップを保存」** で、定期的に控えを取ってください。別のパソコンへ移すときは「バックアップから復元」を使います。
- 見積書のPDF作成時だけ、PDF用のプログラムをインターネット（cdnjs）から読み込みます。

## 「フォルダを開く」の準備（Mac のみ・任意）

Webページから直接 Finder を開くことはできないため、Mac の「ショートカット」アプリを経由します。

1. 「ショートカット」アプリで新しいショートカットを作り、名前を **フォルダを開く** にします。
2. アクション「シェルスクリプトを実行」を追加し、スクリプトに `open "$(cat)"` と入力します。入力は「ショートカットの入力」、入力を渡す方法は「stdinへ」にします。
3. ショートカット → 設定 → 詳細 で「スクリプトの実行を許可」をオンにします。
4. 事件簿の案件ページで、Finder でコピーしたフォルダのパス（⌥⌘C）を貼り付けて保存し、「フォルダを開く」を押します。
